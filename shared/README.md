# shared — 공통 계약 데이터

웹(`web/src/data/`)과 수집 배치(`web/ingest/`)가 **같은 값을 봐야 하는** 정적 데이터다.
`web/scripts/copy-shared.mjs` 가 빌드·개발 시작 시 `web/src/data/` 로 복사한다 —
원본은 항상 이 디렉터리이고, `web/src/data/` 는 수정하지 않는다.

이 파일들은 **조용히 틀리는** 종류의 데이터다. 값이 어긋나도 예외가 나지 않고 화면에도
증상이 없다. 그저 정당한 대상자가 결과에서 빠질 뿐이다. 그래서 네 파일 모두 출처와
기준일자를 파일 안에 적고, 검증 테스트를 붙인다.

| 파일 | 출처 | 기준일자 | 갱신 주기 | 검증 |
|---|---|---|---|---|
| `median_income_2026.json` | 보건복지부 고시 제2025-135호 | 2026-01-01 시행 | 연 1회 (매년 7~8월 고시) | `web/src/lib/median-income.test.mjs` |
| `regions.json` | 행정안전부 행정표준코드 법정동코드 전체자료 | 2026-07-08 스냅샷 | 통폐합·관할 이관 고시 시 | `web/src/lib/regions.test.mjs` |
| `income_deciles.json` | 소득분위 1~10 라벨 (표시 전용) | — | 없음 | — |
| `occupations.json` | 직업 대분류 12종 + 파서 동의어 사전 | — | 사전 보강 시 | `web/ingest/tests/parser.test.ts` |

## 검증이 무엇을 보는가

파일 값을 그대로 읽어 비교하는 테스트는 **아무것도 검증하지 않는다** — 파일이 틀리면
테스트도 같이 틀린다. 그래서 두 파일의 테스트는 파일 밖의 사실과 대조한다.

- **기준중위소득**: 2025년 고시 표에 2026년 발표 인상률(1인 7.20% / 4인 6.51%)을 적용한
  값과 일치하는지. 가구원이 늘수록 인상률이 낮아지는 고시의 형평성 조정 구조도 함께 본다.
- **법정동코드**: 자리수·소속·중복 같은 구조 불변식과, 최근 개편(강원특별자치도 51 /
  전북특별자치도 52 / 군위군 대구 이관 27720)이 반영됐는지.

## 미해결 항목

**`median_income_2026.json` 의 7인 가구 값이 고시 산정식과 40,035원 어긋난다.**
고시는 7인 이상을 "6인 + (6인 − 5인)"으로 정의하는데, 그 식으로는 9,555,185원이 나오고
파일에는 9,515,150원이 들어 있다. 1~6인 값은 발표 인상률과 정확히 맞으므로 7인만 의심된다.
고시 원문 대조가 필요해 임의로 고치지 않았다 — 해결 절차는
`web/src/lib/median-income.test.mjs` 하단의 skip 된 테스트 주석에 적어 두었다.
영향 범위는 7인 이상 가구의 소득 기준액이다.
